# Fast Stocks — Архитектура и спецификация проекта

## 1. Концепция и цели
Персональный аналитический дашборд для одного пользователя-администратора для мониторинга котировок, свечных графиков и тематических новостей по тикерам и ключевым словам без платных API-подписок.

---

## 2. Стек технологий
* **Backend:** Node.js (v20+), Nest.js (REST, WebSockets/SSE для пушей, Cron).
* **База данных / Кэш:** SQLite / PostgreSQL + Prisma (хранение тикеров, закладок, алертов и кэша новостей/свечей).
* **Парсинг и внешние данные:**
  * **Новости:** `rss-parser` + Google News RSS endpoints.
  * **Котировки и свечи:** Yahoo Finance API (библиотека `yahoo-finance2` для Node.js) или Finnhub free tier.
* **Frontend:** React (Vite), TypeScript.
* **Стейт-менеджмент:** MobX-State-Tree (MST) — строгие типизированные модели, снапшоты, асинхронные flow-экшены.
* **Графика и UI:**
  * `lightweight-charts` (от TradingView — золотой стандарт открытых и быстрых свечных графиков).
  * Стилизация: Tailwind CSS + Lucide Icons.

---

## 3. Схема сбора новостей (Google News RSS)
Google генерирует бесплатные RSS-потоки без обязательной авторизации:
* **Поиск по запросу / тикеру:** эндпоинт `https://news.google.com/rss/search?q={QUERY}&hl=ru&gl=RU&ceid=RU:ru`
* **Особенности реализации:**
  1. Кэширование на бэкенде с TTL 5–15 минут, чтобы исключить лимиты запросов (HTTP 429).
  2. Дедупликация новостей по `guid` или оригинальному заголовку.
  3. Обогащение: извлечение имени издания, даты публикации и сниппета.

---

## 4. Источники котировок и свечей
1. **Yahoo Finance (`yahoo-finance2`):**
   * Предоставляет исторические свечи (1m, 5m, 1h, 1d) и текущие котировки без необходимости оплачивать подписку.
   * Охватывает акции США, РФ, крипто-пары, валюты и индексы.
2. **TradingView Lightweight Charts (Фронтенд):**
   * Клиентская отрисовка интерактивных свечей и объемов с поддержкой масштабирования, перекрестия и темной темы.

## 5. Архитектура модулей бэкенда (Nest.js)
```text
src/
├── modules/
│   ├── stocks/          # Получение котировок, исторических свечей (Yahoo Finance)
│   ├── news/            # RSS-парсер, кэширование новостей, фильтрация по тикерам
│   ├── watchlist/       # CRUD пользовательского списка отслеживаемых активов
│   └── analytics/       # Базовые технические индикаторы (SMA, EMA, RSI)
├── shared/
│   ├── cache/           # In-memory или SQLite кэш
│   └── cron/            # Фоновые воркеры обновления данных
└── main.ts
```

---

## 6. Архитектура состояния на клиенте (MobX-State-Tree)
* **StockModel:** тикер, название, текущая цена, процент изменения за 24ч, объем.
* **CandleModel:** time (timestamp), open, high, low, close, volume.
* **NewsModel:** id, title, link, source, pubDate, tickerTag.
* **RootStore:** коллекция watchlist, выбранный актив, массив свечей и новостная лента с flow-экшенами загрузки.
